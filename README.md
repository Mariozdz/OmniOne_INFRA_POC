# OmniOne_INFRA_POC

El presente repositorio contempla la inclusión de distintos ejercicios de infraestructura elaborada mediante la herramienta Terraform. Estas pruebas de concepto se basan en ejercicios de SSH, despliegue de infraestructura para Kubernetes en la nube y la prueba de implementación de una propuesta para la arquitectura de OmniOne OpenDID.

La carpeta Omni contiene la propuesta y elaboración más actual de la infraestructura recomendada para el proyecto de OpenDID.

A continuación se presentan los enlaces a distintos recursos elaborados durante el desarrollo del curso de seguridad en la nube.
